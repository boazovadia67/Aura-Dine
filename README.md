# Aura Dine — MVP

הזמנת שולחן בשיחה קולית בעברית עם העוזר הדיגיטלי של המסעדה. ה-MVP מממש את סעיף 1.1 באפיון: **מסעדת פיילוט אחת** ("אאורה ביסטרו"), שיחה קולית באתר שמסתיימת בהזמנה שנשמרה, וממשק ניהול בסיסי למנהל המסעדה.

## הרצה

דרישות: Node.js 20 ומעלה, ודפדפן **Chrome** או **Edge** עם מיקרופון. ב-Edge יש קולות עבריים טבעיים, ולכן הוא מומלץ.

```bash
npm install
cp .env.example .env        # ומלאו ANTHROPIC_API_KEY ו-SESSION_SECRET
npm run setup               # prisma generate + יצירת מסד SQLite + נתוני פיילוט
npm run dev                 # http://localhost:3000
```

- עמוד המסעדה: http://localhost:3000/r/aura-bistro
- ממשק ניהול: http://localhost:3000/admin. פרטי ההתחברות לסביבת הפיתוח נמצאים ב-`prisma/seed-data.ts`.
- איפוס סיסמה: הקוד "נשלח" למסוף השרת ולטבלת `EmailLog`.
- הודעות SMS: נשמרות בטבלת `SmsLog` ומוצגות בממשק הניהול ("SMS ובקשות חזרה").

בדיקות: `npm test` (מנוע ההזמנות, מניעת הזמנה כפולה במקביל, הסוכן עם לקוח Claude מדומה, התחברות ואיפוס סיסמה). בדיקת טיפוסים: `npm run typecheck`.

## ארכיטקטורה

| שכבה | מימוש |
|---|---|
| דיבור ← טקסט | Web Speech API בדפדפן (`he-IL`), `src/lib/voice/stt.ts` |
| שיחה ופעולות | Claude (`claude-opus-5-5`, effort נמוך לזמן תגובה קצר) עם כלים, `src/lib/agent/*` |
| טקסט ← דיבור | `speechSynthesis` בדפדפן, `src/lib/voice/tts.ts` |
| מערכת הזמנות | Next.js API + Prisma + SQLite. הסכמה מתאימה גם ל-Postgres |
| SMS | ממשק `SmsProvider` עם מימוש מדומה, `src/lib/sms/*` |

שכבות הדיבור ו-SMS מוסתרות מאחורי ממשקים קטנים, כך שאפשר להחליף אותן בהמשך ב-Azure, Google, ElevenLabs או Twilio.

### החלטות מימוש מרכזיות
- **מניעת הזמנה כפולה (9.4):** כל הזמנה כותבת שורה בטבלת `TableSlot` לכל חלון של 30 דקות שהיא תופסת, עם אילוץ ייחודיות על (שולחן, חלון). שתי בקשות מקבילות לא יכולות לקבל את אותו שולחן, גם תחת עומס. יש בדיקה שמריצה 10 בקשות במקביל.
- **אישור רק אחרי שמירה (10.1, 12.2, 20):** מסך הסיום שואל את מסד הנתונים אילו הזמנות נשמרו בשיחה, ולא מסתמך על מה שהסוכן אמר.
- **הפרדה בין מסעדות (18):** `restaurantId` נלקח תמיד מהסשן בצד השרת ולא מהמודל או מהלקוח, וכל שאילתה מסוננת לפיו.
- **מסעדה סגורה (11):** נאכף בשרת, לא רק בהנחיות לסוכן. ההגדרה `allowBookingWhenClosed` כבויה כברירת מחדל ומאפשרת לשנות זאת, כי הכלל הזה סותר את הבטחת הזמינות 24/7 בהצעת הערך.
- **חלופות (9.8):** בדיוק שתי שעות, אחת מוקדמת ואחת מאוחרת, ואם אין בשני הצדדים, שתי השעות הקרובות ביותר. אחר כך חיפוש באותו יום, ואחר כך הצעה לתאריך אחר.
- **העברה לנציג (7.3):** בשיחה מבוססת דפדפן אין העברה חיה. הסוכן אוסף שם וטלפון ויוצר בקשת חזרה שמופיעה בממשק הניהול (החלטה פתוחה 14).
- **השיחה נפתחת בחלון על עמוד המסעדה, ולא בעמוד נפרד:** דפדפנים מאפשרים השמעת קול רק אחרי לחיצה של המשתמש, וההרשאה הזו לא עוברת למעבר עמוד.

## English summary
Hebrew voice table-booking MVP for a single pilot restaurant.
- **Stack:** Next.js 16 + TypeScript + Tailwind; Prisma 7 + SQLite; Claude (`claude-opus-5-5`) with tool use for the conversation; browser Web Speech API for STT and TTS; SMS is mocked.
- **Setup:** `npm install`, copy `.env.example` to `.env`, then `npm run setup` and `npm run dev`. Use Chrome or Edge with a microphone. Run the tests with `npm test`.
